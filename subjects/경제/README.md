# 경제 암기 퀴즈

고등학교 「경제」의 개념과 용어를 다섯 방향으로 반복해서 외우는 프로그램.
[`quiz` 스킬](../../.claude/skills/quiz/SKILL.md)로 만든 두 번째 과목이고, [문학과 영상](../문학과영상/)과
엔진이 같습니다.

## 실행

### 파일 하나로 (PC)

**`경제-퀴즈.html`** 이 파일 하나만 받아서 더블클릭하면 됩니다.
폴더 구조도, 인터넷도 필요 없습니다(글꼴이 있으면 더 예쁘게 보일 뿐입니다).

태블릿·휴대폰에서는 내려받은 HTML 을 브라우저로 여는 길이 막혀 있어 파일 방식이 통하지 않습니다.
그때는 `gyeongje-web.html` 을 Artifact 로 발행해 링크로 엽니다.

### 저장소를 통째로 받았다면

`index.html` 을 여세요. 단, `data/` 폴더가 **같은 자리에 함께 있어야** 합니다.

## ⚠️ 범위와 출처 — 먼저 읽어 주세요

**이 데이터는 학습지나 교과서를 보고 옮긴 것이 아닙니다.**
고등학교 「경제」 교과서에서 공통으로 다루는 **표준 용어와 정의**로 채웠습니다.

- 개념과 정의 자체는 교과서가 대체로 같습니다. 그래서 지금 이대로도 공부가 됩니다.
- 그러나 **단원 구분·서술의 표현·시험 범위는 학교와 교과서마다 다릅니다.**
  단원 구성은 교과서들이 흔히 쓰는 다섯 영역(경제생활·시장·국가·세계·금융)을 따랐습니다.
  교과서에 따라서는 **011 금융 생활**이 「경제」가 아니라 「금융과 경제생활」 과목에 들어 있습니다.
- 시험은 학습지의 표현으로 나옵니다. **학습지를 주시면 그 문장으로 갈아 끼우겠습니다.**

학습지를 반영할 때 하는 일:

1. `data/items.js` 의 `features` 를 학습지 문장으로 교체
2. `UNITS` 를 학습지 단원 구조에 맞추고, 번호(`no`)를 학습지 번호로
3. 범위 밖 단원에 `exam:false` — 자료는 남고 처음에는 선택되지 않습니다
4. 이 절을 고쳐 무엇을 어디서 가져왔는지 다시 적습니다

### 이 앱이 하지 않는 것 — 계산 문제

경제 시험에는 기회비용·탄력성·GDP·실업률을 **계산하는** 문제가 많이 나옵니다.
이 엔진은 "개념 ↔ 설명" 을 묻는 도구라서 계산 문제는 내지 않습니다. 계산의 **원리**
("명목 GDP를 실질 GDP로 나눈 뒤 100을 곱한 값이다")까지만 외우게 합니다.
계산 연습은 문제집으로 따로 하세요.

## 문제 유형

같은 데이터에서 엔진이 다섯 가지를 만들어 냅니다. 홈에서 하나만 골라 풀 수도 있습니다.

| 유형 | 형태 | 예 |
|---|---|---|
| 이름 쓰기 | 설명 보고 이름 **타이핑** | "이미 지출하여 되찾을 수 없는 비용이다" → `매몰 비용` |
| 설명 고르기 | 이름 → 옳은 설명 5지선다 | "외부 불경제에 대한 설명으로 옳은 것은?" |
| 설명 → 이름 | 설명 → 이름 5지선다 | "거래한 뒤에 감추어진 행동 때문에 생긴다" → 도덕적 해이 |
| O·X 판별 | 붙여 준 서술이 그 개념의 것인지 판단 | "최저 가격제 — 소비자를 보호하려는 목적" → X (최고 가격제) |
| 떠올리기 | 보지 않고 떠올린 뒤 확인 | "환율 상승의 설명을 떠올려 보세요" → 3가지 확인 |

**오답 보기는 지어내지 않습니다.** 전부 다른 항목의 진짜 설명이고, **헷갈리는 짝에서 먼저**
길어옵니다. 걸어 둔 짝의 예:

| 짝 | 왜 헷갈리나 |
|---|---|
| 수요량의 변화 / 수요의 변화 | 곡선 위의 이동이냐 곡선 자체의 이동이냐 |
| 대체재 / 보완재, 정상재 / 열등재 | 방향만 반대다 |
| 탄력적 / 비탄력적 / 단위 탄력적 | 한 글자 차이, 판매 수입의 방향이 갈린다 |
| 최고 가격제 / 최저 가격제 | 누구를 보호하고 무엇이 남는가 |
| 역선택 / 도덕적 해이 | 거래 전이냐 후냐 |
| 공공재 / 공유 자원, 비경합성 / 비배제성 | 두 성질의 조합 |
| 명목 / 실질 GDP, 명목 / 실질 이자율 | 물가를 걷어 냈느냐 |
| 마찰적 / 구조적 / 경기적 실업 | 원인과 대책이 다르다 |
| 재정 정책 / 통화 정책 (확대·긴축) | 누가 무엇을 조절하나 |
| 절대 우위 / 비교 우위 | 생산비냐 기회비용이냐 |
| 환율 상승 / 환율 하락 | 수출·물가·외채 효과가 반대다 |
| 본원 소득 수지 / 이전 소득 수지 / 서비스 수지 | 무엇을 어디에 적나 |

## 채점

- 괄호·띄어쓰기·가운뎃점은 무시합니다 — `국내 총생산` = `국내총생산` = `GDP`
- `GDP`/`국내총생산`, `GNI`/`국민총소득` 은 같은 말로 칩니다 — `실질 국내 총생산` = `실질 GDP`
- 꼬리말 `정책`·`제도` 는 있으나 없으나 정답 — `통화` = `통화 정책`, `변동 환율` = `변동 환율 제도`
- 다른 이름도 받습니다 — `카르텔`(담합), `사회적 잉여`(총잉여), `원화 가치 하락`(환율 상승) 등
- 오타 한 글자는 "정답 · 오타" 로 봐주되, **서로 한 글자 차이인 이름은 봐주지 않습니다** —
  `탄력적`/`비탄력적`, `단리`/`복리` 에서 오타를 봐주면 한쪽을 쓰고 다른 쪽 정답을 받습니다

## 기능

- 단원 단위 또는 세부 갈래 단위로 범위 선택
- 오답 우선 출제, 오답 노트 다시 풀기, 연속 3회 정답 시 숙달 처리
- 학습 기록은 브라우저에 저장(localStorage)

## 구성

```
index.html      앱 전체 (UI + 퀴즈 엔진) — 과목마다 고치지 않는다
data/items.js   문제 데이터 185항목 · 서술 405개  ← 고치는 곳은 여기뿐
build.py        데이터를 인라인해 단일 HTML 생성
verify.js       데이터 계약 검사
smoke.js        실제 브라우저로 한 세션을 끝까지 풀어 보는 종단 시험
경제-퀴즈.html        배포용 단일 파일 (build.py 산출물)
gyeongje-web.html    Artifact 발행용본
docs/PRD.md     요구사항 정의서
```

## 고친 뒤

```bash
node verify.js      # 데이터 계약 — ERROR 가 있으면 고친다
python3 build.py    # → 경제-퀴즈.html (문법 검사 포함)
node smoke.js       # 진짜 브라우저로 한 세션 (playwright 필요, 없으면 건너뜀)
```

**빌드를 안 돌리면 산출물은 옛것 그대로입니다.**

## 항목 추가

`data/items.js` 의 `ITEMS` 배열에 객체를 하나 넣으면 됩니다.

```js
{ id:"dm11", category:"dnd", name:"기펜재",
  features:["가격이 오르면 오히려 수요량이 늘어나는 재화다",
            "열등재 가운데 소득 효과가 대체 효과보다 큰 경우다"],
  confuse:["dm10"] }
```

- `id` 는 **한번 정하면 안 바꿉니다** — 학습 기록의 열쇠라서, 바꾸면 그 항목의 진도가 날아갑니다
- 서술 안에 **그 항목의 이름을 쓰지 않습니다** — 답이 그대로 새어 나갑니다
- 헷갈리는 짝은 **서로** `confuse` 로 걸어 둡니다 (위 예라면 `dm10` 쪽에도 `"dm11"` 을)

새 갈래는 `CATS` 에 한 줄을 넣고 그 단원의 `cats` 에도 키를 더합니다.
자세한 계약은 [`data-schema.md`](../../.claude/skills/quiz/references/data-schema.md).
