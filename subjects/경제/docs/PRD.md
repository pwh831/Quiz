## 1. 개요

### 1.1 배경

「경제」는 비슷한 말이 짝을 지어 나온다. 수요량의 변화와 수요의 변화, 역선택과 도덕적 해이,
명목과 실질, 절대 우위와 비교 우위, 재정 정책과 통화 정책 — 하나씩 보면 쉽고 시험지에서
나란히 놓이면 갈리지 않는다. 게다가 개념마다 **방향**(오르면 무엇이 늘고 무엇이 주는가)이
붙어 있어 반대로 외우기 쉽다.

종이 정리본은 답이 옆에 보여서 "아는 것 같은 느낌"만 남는다. **직접 쓰고 틀리는 것을
확인하는** 것이 이 프로그램의 존재 이유다.

`quiz` 스킬의 엔진을 그대로 쓰고 데이터만 새로 채웠다. 엔진은 한 줄도 고치지 않았다.

### 1.2 목표

- 헷갈리는 짝을 **한 문제 안에서 함께 보여** 가르는 연습을 시킨다.
- 고르는 것으로 끝내지 않고 **직접 타이핑**해서 쓸 수 있는지 확인한다.
- 틀린 항목을 추적해 맞을 때까지 반복 노출시킨다.
- 단원·갈래를 골라 오늘은 이것만 풀 수 있게 한다.
- 파일 하나로 어디서나 열린다.

### 1.3 비목표

- **계산 문제** — 기회비용·탄력성·GDP·실업률 계산. 이 엔진은 개념과 설명을 잇는 도구다.
  계산의 원리를 한 문장으로 외우게 하는 데까지만 한다.
- **그래프 해석 문제** — 수요·공급 곡선의 이동을 그림으로 묻는 문제. 필요하면 그래프
  그림을 `MEDIA` 로 넣어 '그림 보고 이름 쓰기'로 확장할 수 있다.
- 서술형 답안 채점, 다중 사용자 계정, 서버, AI 자동 문제 생성

### 1.4 성공 기준

- 헷갈리는 짝이 5지선다 보기에 함께 올라온다.
- 한 세션(20문항)을 5분 안에 푼다.
- 오답이 정답 처리될 때까지 반복 출제된다.
- 새로고침·재접속 뒤에도 진도가 남는다.
- 휴대폰 너비에서 가로 스크롤이 생기지 않는다.

## 2. 사용자

| 구분 | 설명 |
|---|---|
| 주 사용자 | 「경제」 수강생 본인 (단일 사용자) |
| 사용 환경 | 태블릿·휴대폰 우선, PC 브라우저도 지원 |
| 사용 시점 | 시험 2~3주 전부터 매일 10~20분 |

**핵심 사용자 스토리**

1. 오늘은 시장 실패만 — 갈래를 골라 풀고 싶다.
2. 설명을 보고 개념 이름을 **직접 써 보고** 맞았는지 확인하고 싶다.
3. 역선택과 도덕적 해이가 매번 헷갈린다. 둘을 나란히 놓고 가르는 연습을 하고 싶다.
4. 환율이 오르면 무엇이 좋아지고 나빠지는지 한 번에 떠올리고 싶다.
5. 틀린 것만 모아서 다시 풀고 싶다.

## 3. 데이터

### 3.1 범위

185항목 · 서술 405개 · 11단원 · 20갈래 · 5영역. 구성은 [README](../README.md) 참고.

### 3.2 출처 — 알려진 한계

**현재 데이터는 고등학교 「경제」 교과서의 표준 용어로 채운 것이고,
사용자의 학습지나 교과서를 보고 옮긴 것이 아니다.**

개념과 정의는 교과서가 대체로 같으므로 지금 이대로도 공부가 된다. 그러나
단원 구분·서술의 표현·시험 범위는 학교마다 다르고, **시험은 학습지의 표현으로 나온다.**
특히 금융 단원(011)은 교육과정·교과서에 따라 「금융과 경제생활」로 빠져 있을 수 있다.

학습지를 받으면 `features` 를 그 문장으로 갈아 끼우고, `UNITS` 를 학습지 단원 구조에
맞추고, 범위 밖 단원에 `exam:false` 를 달고, README 의 '범위와 출처'를 고친다.
**앱 코드는 건드릴 것이 없다.**

시점에 따라 바뀌는 사실(예금자 보호 한도 등)은 `features` 에 넣지 않고 `notes` 로 뺐다.

### 3.3 서술의 규칙

- 서술 안에 그 항목의 이름을 쓰지 않는다 (답이 새어 나간다)
- 한 문장에 한 가지 (O·X 에서 반만 맞는 문장이 되면 안 된다)
- 그 항목에만 해당하게 (설명 → 이름의 답이 둘이 되면 안 된다)
- 항목당 2~4개 (하나면 매번 같은 문제, 다섯이 넘으면 떠올리기가 불가능)

## 4. 기능

### 4.1 다섯 유형

유형은 데이터에 적지 않는다. 같은 항목에서 엔진이 다섯 가지를 만든다.
자세한 것은 [`question-types.md`](../../../.claude/skills/quiz/references/question-types.md).

### 4.2 헷갈리는 짝 (`confuse`)

오답 보기를 **`confuse` → 같은 갈래 → 같은 영역 → 전체** 순으로 길어온다.
모든 짝은 양방향으로 걸었다(`verify.js` WARN 0). 짝 목록은 README 참고.

### 4.3 채점

[`grading.md`](../../../.claude/skills/quiz/references/grading.md) 참고.
이 과목에 건 규칙: 꼬리말 `정책`·`제도`, 같은 말 `GDP`/`국내총생산`·`GNI`/`국민총소득`.
모든 이름과 다른 이름을 이 규칙으로 대조해 **두 항목에 동시에 맞는 답이 없음**을 확인했다.

한 글자 차이인 이름(`탄력적`/`비탄력적`, `단리`/`복리` 등)은 엔진이 자동으로 찾아내
오타 관용에서 뺀다.

## 5. 기술

| 항목 | 결정 | 이유 |
|---|---|---|
| 빌드 도구 | 없음 | 파일 하나로 돌아야 한다 |
| 엔진 | `index.html` 고정 (스킬 원본 그대로) | 과목마다 고치면 고친 것이 한쪽에만 남는다 |
| 저장 | localStorage (`gyeongje-v1`) | 서버 없이 진도가 남는 유일한 길 |
| 그림 | 쓰지 않음 | 개념 암기는 텍스트로 성립한다 |
| 검사 | `verify.js` + `build.py` 문법 검사 + `smoke.js` | 데이터 · 코드 · 실제 화면을 각각 본다 |
